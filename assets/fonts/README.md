# ReelsForge fonts

Optional. Place licensed TTF or OTF files here. The styles look for Cairo
Regular/Bold and Amiri Regular, then use installed alternatives such as
DejaVu Sans and Segoe UI. Set `REELSFORGE_FONT` to an absolute path to prefer
one font throughout the app. ReelsForge checks glyph coverage before drawing.
Restart Streamlit after installing fonts.
